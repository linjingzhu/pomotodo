# Pomodoro Timer (뽀모도로 타이머)

설치형 Windows 앱. Electron(웹 기술로 데스크톱 앱을 만드는 프레임워크) 기반.

## 다운로드

[소개 웹페이지](https://linjingzhu.github.io/pomotodo/)에서 기능 설명을 보거나,
[Releases](https://github.com/linjingzhu/pomotodo/releases/latest)에서 바로
`PomodoroTimer-Portable-<버전>.exe`(설치 없이 바로 실행하는 포터블 버전)를 받아
원하는 폴더에 두고 실행하면 됩니다. 공개 저장소라 로그인 없이 누구나 받을 수
있습니다.

새 버전 배포: `package.json`의 `version`을 올려서 push하면 GitHub Actions
(`.github/workflows/release.yml`)가 Windows 설치 파일을 빌드해 `v<버전>`
Release로 올립니다. 버전은 electron-builder가 요구하는 semver 형식을 맞추기
위해 0.x.0으로 표기하며(예: 0.1.0), 빌드마다 x를 1씩 올리고, 정식 릴리즈로
확정되면 1.0.0으로 올립니다 (앱 안 Settings 탭 맨 아래 About에 현재 버전
표시). 공개 저장소에서는 일반 러너 기준으로 Actions가 무료이고,
그 밖에도 비용이 들지 않도록 다음처럼 제한되어 있습니다.
- 사용 시간이 1배로 계산되는 Linux 러너만 사용 (Windows 러너는 2배)
- 이미 있는 버전이면 빌드를 건너뜀
- 실행 시간 상한 설정
- 과금되는 워크플로 아티팩트는 저장하지 않음

## 빌드 방법 (최초 1회, 인터넷 필요)

1. `build.bat` 더블클릭
   - 또는 터미널에서: `npm install` → `npm run dist`
2. 완료되면 `dist` 폴더에 `PomodoroTimer-Portable-<버전>.exe`가 생성됩니다
   (설치 없이 바로 실행하는 포터블 버전. 설치형은 만들지 않음)

Node.js 22.13 이상(22.x) 또는 24 이상이 필요합니다. https://nodejs.org 에서
LTS 버전을 설치한 뒤 진행하세요.

### 빌드가 실패할 때 (dist 폴더가 안 생길 때)

`build.bat`는 `npm run dist`의 전체 출력을 이 폴더의 `build.log`에도 저장합니다.
가장 흔한 원인은 Windows "개발자 모드"가 꺼져 있어서 electron-builder가 내부적으로
필요한 심볼릭 링크를 만들지 못하는 경우입니다 (`build.log`에 "symbolic link" 또는
"privilege" 같은 단어가 보이면 이 경우) — 설정 → 개인 정보 및 보안 → 개발자용 →
"개발자 모드" 켜기, 또는 `build.bat`를 관리자 권한으로 실행 후 다시 시도하세요.

## 개발 중 실행 (빌드 없이 바로 테스트)

```
npm install
npm start
```

## 정적 검사와 회귀 테스트

```sh
npm ci
npm run check
npm run dist -- --publish never
```

`check`는 ESLint와 Node 테스트를 실행합니다. 타이머의 시계 변경·절전·일시정지,
종료 시 기록 저장과 실패 재시도, 기록 파일 보존, 창 수명주기를 검증합니다.
운영체제의 실제 절전·알림·다중 모니터 동작은 Windows에서 별도로 확인해야 합니다.
배경 이미지는 최대 20 MB까지 읽으며, 더 큰 파일을 선택하면 오류를 표시합니다.

## 구현된 기능

- 작업/쉬는 시간 설정 (기본 25분 / 5분), 변경 즉시 저장
- 긴 휴식: 집중을 정해진 횟수(기본 4회)만큼 마치면 짧은 휴식 대신 긴 휴식(기본
  15분). 둘 다 설정에서 변경. Reset Session을 누르면 횟수도 처음부터
- 자동 시작 선택: "Start breaks automatically" / "Start focus automatically"를
  각각 켜고 끌 수 있음 (기본 둘 다 켜짐). 끄면 해당 단계가 전체 시간으로 준비된
  채 시작 버튼을 기다림
- 작업표시줄 아이콘에 진행 막대 표시 (진행 중 초록, 일시정지 노랑, 대기 중 없음).
  트레이 아이콘에 마우스를 올리면 현재 단계와 남은 시간 표시 (트레이에 있을 때는
  작업표시줄 아이콘이 없으므로)
- 항상 위 표시 (always on top)
- 제목 표시줄 없이, 아이폰 느낌의 둥근 모서리 위젯 하나로 표시 (창 자체가
  투명해서 모서리 바깥은 바탕화면이 그대로 비침)
- 기능 버튼은 평소엔 숨겨져 있다가 위젯에 마우스를 올리면 지름 10px의 작은
  원으로 나타남 (아이콘 없이 순수한 점, 각각 마우스를 올리면 툴팁으로 이름
  표시). 우상단에 위부터 닫기 · 크기 고정 · 전체화면 · Reset Size 4개, 타이머 영역 우하단에
  패널(Goals · Calendar · Settings) 버튼 1개 (패널을 펼치면 패널 바로 위로
  따라 올라감).
  크기 고정 점만 속이 빈 원 ↔ 채워진 원으로 창 크기 고정 상태를 표시
- 전체화면 ↔ 창 모드 전환 (우상단 전체화면 점, 위젯 빈 곳을 더블클릭, 또는
  전체화면에서 ESC). 버튼·입력 칸·패널 위에서의 더블클릭은 전환하지 않음.
- 창 이동: 위젯의 빈 곳(타이머 링 포함)을 드래그. 3px 이상 움직여야 이동이
  시작되어 클릭·더블클릭으로는 창이 밀리지 않음. 전체화면에서는 이동 불가
  크기를 고정한 상태에서도 전환되며, 창 모드로 돌아오면 전체화면에 들어가기
  직전의 크기·위치로 정확히 복귀. 전체화면에서는 창을 옮기거나 가장자리를
  드래그해 크기를 바꿀 수 없음(잠김)
- 창 가장자리·모서리를 드래그해 크기 조절 (크기 고정 중이거나 전체화면이면 불가).
  투명 창은 Windows 기본 테두리로 크기를 바꿀 수 없어서 앱이 직접 처리함
- 창 기본 크기: 340×470 (타이머만 보이는 크기). 패널을 펼치면 창이 아래로 늘어나고
  (높이 780, 화면 아래가 모자라면 위로 올라감) 접으면 원래 크기·위치로 돌아옴.
  우상단 마지막 점 **Reset Size**로 언제든 기본 크기로 되돌림 (크기 고정 중에도
  동작, 전체화면에서 누르면 기본 크기의 창 모드로 전환)
- 얇은 원형 게이지로 남은 시간 표시 (타이머 숫자 주변 링, 시간이 지날수록
  채워진 부분이 줄어듦), 시작/일시정지·초기화 버튼은 색 없는 투명 유리 원형 아이콘
- 게이지 모양은 설정의 Gauge style에서 선택: Filled pie(기본, 원 안쪽 전체를
  부채꼴로 채움) 또는 Stroke(테두리 링만)
- 타이머 상태를 한눈에 구분
  - 멈춤(시작 전·초기화): 색 없이 링이 비어 있고 숫자가 흐림
  - 동작 중: 빛번짐이 있는 그라디언트 게이지. 줄어드는 쪽 끝(지금 이 순간)이 키
    컬러로 가장 진하고, 12시 쪽 끝으로 갈수록 이웃 색조로 옅어짐 (빨강 →
    주황, 터크와즈 → 파랑)
  - 일시정지: 링이 흐려지고 빛번짐이 꺼지며 숫자가 천천히 깜박임 (Windows
    "애니메이션 효과"를 끄면 깜박임 대신 고정된 흐림)
  - 작업↔휴식 전환 순간: 링이 새 색으로 시계 방향으로 다시 차오름
- 조작 버튼(시작/일시정지·초기화) 옆에 작업↔휴식 전환 버튼. 누르면 지금
  단계를 끝내고 바로 다른 단계로 넘어감 (자연히 끝난 것으로 치지 않아, 작업
  중이었다면 1분 이상 했을 때만 "stopped early"로 기록되고 Total turns는
  늘지 않음. 항상 짧은 휴식으로 이동하며, 어느 쪽 휴식에서든 작업으로는 바로
  복귀)
- 조작 버튼 아래에 누적 기록 표시 (앱을 다시 켜도 유지). 라벨은 링의 왼쪽 끝,
  숫자는 오른쪽 끝에 맞춰 정렬. 창을 작게 줄이면 링과 숫자가 함께 작아져서
  기록과 Reset Session 버튼이 잘리지 않음
  - Total turns: 끝까지 마친 작업 세션 수
  - Total study time: 작업 모드에서 실제로 흐른 시간의 합 (중간에 그만둔
    세션도 포함, 휴식 시간은 제외, 예: `3h 5m`)
  - Reset Session 버튼: 누르면 정말 초기화할지 먼저 확인 창이 뜨고, 확인하면
    바로 두 기록을 0으로 만들고 타이머도 완전히 초기화해 작업 모드의 시작 전(대기)
    상태로 돌아감 (휴식 중이었어도). 타이머의 초기화(↻)는 기록에 영향 없음
- 앱 화면의 모든 글자(설정 항목, 툴팁, 트레이 메뉴, Windows 알림)는 영어
- **세션 목표**: 조작 버튼 아래 "Goal for this session" 칸에 적어 두면 집중
  세션이 끝날 때 시작·종료 시각, 실제 공부한 시간과 함께 PC에 저장됨 (1분 이상
  하다가 초기화한 세션도 "stopped early"로 저장)
  - 입력 후 Enter를 누르면 목표로 확정되어 Goals 목록에 추가 (같은 이름의 미달성
    목표가 있으면 중복으로 넣지 않고 그 목표를 사용)
  - Goals 목록에서 목표 이름을 누르면 타이머의 목표로 설정되고, 현재 목표는
    목록에서 키 컬러로 표시
  - 목표 칸에 마우스를 올리면 왼쪽에 원형 체크 박스가 나타나 그 목표의 달성 여부를
    표시하고, 누르면 달성 ↔ 미달성이 바뀜. 달성으로 체크하면 Goals 목록의 다음
    미달성 목표를 자동으로 불러오고, 모든 목표가 달성된 상태면 그 목표를 유지
- **패널 (타이머 영역 우하단 점)**: Goals · Calendar · Settings 세 탭
  - Goals: 맨 위에 오늘 날짜·요일과 초 단위 현재 시각 표시(시각은 키 컬러로
    강조), 시간대 선택 가능(Local·UTC·KST 등, 다음 실행 시에도 유지). 목표를
    그룹으로 묶을 수 있음(그룹 생성·이름 변경·삭제, 그룹 삭제 시 그 안의 목표는
    그룹 없음으로 이동). 목표는 드래그해 순서를 바꾸거나 다른 그룹 제목 위에
    놓아 그 그룹으로 옮길 수 있음(드래그 중에는 마우스 아래 항목이 반투명하게
    따라오고, 놓일 위치에 선으로 표시). 각 목표 옆 ✎ 버튼으로 이름 변경, 달성하면
    체크(달성일 기록), 필요 없으면 삭제
  - Calendar: 월 달력에 날마다 공부량을 키 컬러 계열 5단계로 표시 (0~1시간
    미만은 표시 없음, 이후 1시간 단위로 한 단계씩 채도가 높아져 1시간은 옅은
    파스텔, 4시간 이상은 키 컬러 그대로의 가장 선명한 색,
    달력 아래 Less→More 범례, 각 칸에 마우스를 올리면 날짜와 공부 시간), 오늘은
    밝은 오렌지 테두리로 표시. 날짜를 누르면 그날의 세션 목록과 달성한 목표가
    나오고, 세션 메모는 나중에 고칠 수 있음. 세션과 달성한 목표는 각각 옆의 ×
    버튼으로 삭제 가능 (목표 삭제는 Goals 목록에서도 사라짐). 기록은 이 PC에만
    저장되고 외부 캘린더와 연결하지 않음
- 모니터 선택 후 좌상/우상/좌하/우하 4개 모서리로 창 붙이기
- 집중 시간·휴식 시간이 끝날 때마다 Windows 알림 + **Windows 알람 소리 1회**, 작업↔휴식
  자동 전환. 알림은 자동으로 사라지지 않고, 사용자가 알림의 Dismiss 버튼이나
  알림 자체를 누르거나 앱에서 시작/일시정지/초기화를 누를 때까지 남음. 새
  알림이 오면 이전 알림은 교체됨. 알림은 설정에서 끄고 켤 수 있음 (기본 켜짐).
  알림을 끄면(또는 알림을 띄울 수 없으면) 대신 앱 자체 알림음 1회가 울림.
  Windows 방해 금지(집중 지원)가 켜져 있으면 알림과 소리가 함께 숨겨짐
- 타이머는 실제 시계 기준으로 계산되어, 창을 트레이로 보내거나 최소화해도
  정확히 흐르고 제때 전환·알림됨. PC가 절전 모드에 들어가면 일시정지되고, 깨어난
  뒤에도 일시정지 상태로 남음 (절전 시간은 공부 시간에 포함되지 않음)
- 시스템 트레이 아이콘 (좌클릭: 창 보이기/숨기기, 우클릭: 열기/종료 메뉴)
- 최소화 시 트레이로 보내기 (설정에서 끄고 켤 수 있음, 기본 켜짐)
- 닫기(X)를 누르면 Quit(종료) / Hide to Tray(트레이로 숨기기) / Cancel(취소) 중
  선택하는 확인창 표시. 설정의 "Close to tray (keeps running)"를 켜면 묻지 않고
  바로 트레이로 숨김 (기본 꺼짐)
- 리퀴드 글라스(Liquid Glass) 디자인: 깊은 블러 + 채도 강조로 배경이 유리에
  비치듯 보이고, 상단 밝은 하이라이트/하단 그림자로 두꺼운 유리 질감 표현.
  버튼은 알약/원형으로, 링에는 은은한 글로우 적용. 설정 패널은 텍스트
  가독성을 위해 더 어둡게 처리
- 배경 이미지 지정 (짧은 쪽에 맞춰 창을 꽉 채우고 긴 쪽은 잘림), 배경 블러,
  배경 틴트(색상 + 강도) 설정
  - 고른 이미지는 앱 데이터 폴더(`%APPDATA%\Pomodoro Timer\background.<확장자>`)로
    복사해 두고 그 사본을 사용하므로, 원본을 옮기거나 지워도 배경이 유지됨. 새로
    고르면 사본이 교체되고, Clear를 누르면 사본도 삭제됨
  - "Match window to image ratio": Keep width(현재 너비 유지) / Keep height(현재
    높이 유지)를 누르면 나머지 한 변을 조절해 창을 이미지의 가로세로 비율에
    맞춤. 화면보다 커지면 비율을 유지한 채 화면에 맞게 줄이고, 고정(핀)
    상태나 전체 화면에서도 동작. 블러가 0이면 이미지가 잘림 없이 전부 보임
- 키 컬러(포인트 색상) 설정 — 작업 모드의 원형 게이지·시작 버튼 등에 반영
  (휴식 모드는 항상 터크와즈 색 고정)
- 마지막 설정(작업/휴식 시간, 항상 위 여부, 트레이 관련 옵션, 배경/틴트/키
  컬러, 창 크기)은 다음 실행 시에도 유지
- **Settings 탭**
  - 항목이 Timer · Window · Display · Background · Appearance · Data로
    묶여 각각 제목이 붙어 있음
  - Monitor · Gauge style은 앱 디자인에 맞춘 자체 드롭다운 (여닫는 목록의
    선택 색이 키 컬러를 따름, Windows 기본 드롭다운의 파란 강조색이 아님)
  - **Data**: 저장된 Goal·Calendar 기록을 전부 삭제(확인창 있음, 기록이
    없으면 버튼 비활성)하거나, 이 탭의 모든 설정을 기본값으로 되돌리는(확인창
    없음, 배경 이미지도 함께 초기화) 버튼
  - 맨 아래 About: 만든이("Designed by Lim Jeongsu")와 현재 버전 표시
- 타이머 영역과 Settings 패널 사이의 경계를 위아래로 드래그해 둘의 높이 비율
  조절 (창 크기가 달라져도 비율로 유지되고, 다음 실행 시에도 유지)

> **참고:** 창이 완전히 투명해서, 위젯의 실제 느낌(특히 유리 효과의 밝기)은
> 그 뒤에 무엇이 있는지(바탕화면, 다른 창)에 따라 달라집니다. 이 문서의
> 스크린샷과 실제 화면이 다르게 보일 수 있습니다.
